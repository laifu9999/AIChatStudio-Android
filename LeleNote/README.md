# 乐乐速记 LeleNote

边看视频边记笔记的 Android 记事本。当前版本 v1.2（versionCode 3）。

## 功能

- **悬浮球**：授权「显示在其他应用上层」后，小球常驻任何应用最上层，可拖动换位（横竖屏实时适配）
- **点球弹菜单（v1.2）**：点击悬浮球弹出功能菜单——「📝 记笔记」（视频自动暂停→半透明速记页，横屏键盘不挡输入框）和「📖 笔记目录」（打开主界面查看/修改/删除所有笔记）；点菜单外或再点球关闭
- **免授权截图（推荐）**：在系统无障碍设置开启「乐乐速记·免授权截图」一次，之后点「📷 截图」直接全屏抓帧，不再弹授权、不用选共享目标（Android 11+）
- **旧版截图**：Android 10 及以下走 MediaProjection，每次需系统授权
- **自动续播**：保存或关闭速记页后，视频自动继续播放（媒体键）
- **看图**：编辑页与阅读窗的截图均可点击全屏查看（双指缩放、双击复位、单击关闭）
- **笔记管理**：近全屏详情（正文可滚动）/编辑/删除/分享
- **导出 JSON**：全部笔记（文字+截图内嵌）导出为 JSON，可存到任意网盘 App（百度网盘、阿里云盘等）
- **导出 Word（v1.2）**：全部或单条笔记导出为 .docx（截图等比内嵌、按行分段），用 WPS/Word/手机 Office 直接阅读；零依赖手工打包 OOXML
- **导入**：从网盘/文件管理器选 JSON 备份恢复

## 说明

- 暂停/续播走媒体键（AudioManager 派发 KEYCODE_MEDIA_PAUSE/PLAY），对绝大多数视频 App（YouTube、B站、抖音、浏览器等）有效；个别不响应媒体键的播放器除外
- 截图基于 MediaProjection，每次首次截图需系统授权；Android 14+ 由前台服务承载
- 笔记与截图存储在应用私有目录，卸载即清空，重要内容请导出备份

## 构建

GitHub Actions 自动构建：push 即跑 `gradle assembleDebug`，产物在 Artifacts（LeleNote-APK）。

技术栈：Kotlin + Jetpack Compose（Material3），minSdk 26 / targetSdk 35，AGP 8.7.3 / Kotlin 2.0.21。
