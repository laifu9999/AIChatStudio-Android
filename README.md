# 乐乐写小说（LeLe-NovelMaster）

一个**原生安卓 AI 长篇小说创作APP**：对接各大 AI（含免费模型）、300 章不跑题、全界面化操作、自动写完所有章节并逐章保存。

## v2.0 聊天版（主界面 = 和 AI 聊天，像豆包/元宝）

- **聊天即操作**：主界面为对话气泡流，所有功能既能点界面也能用一句话完成
- **AI 工具执行协议**：AI 理解自然语言后直接执行 —— 「我想写一本都市文，主角叫林墨…」自动建书并生成整套设定卡；「把这段存到人物设定卡」「写下一章」「开始自动写作 1 到 50」都会真正落库执行，执行结果以绿色卡片回显
- **本地快速路由**：确定性口令（写下一章/列出设定卡/停止写作等）本地直接执行，不消耗 token
- **聊天记录持久化**：按项目分库保存，抽屉菜单可清空
- **章节移动/复制**：聊天说「把第5章移到第8章」「复制第3章」即可
- 顶栏切换当前小说；右上抽屉进入：项目仪表盘 / 设定卡 / 章节列表 / 自动写作控制台 / AI模型 / 导出发布

## 功能总览

- **书架管理**：新建小说（自定义目标章数/每章字数）、导入 TXT 自动分章建书、删除
- **设定卡系统**（一致性核心）：全书大纲 / 世界观 / 人物设定 / 主线剧情 / 支线任务 / 伏笔钩子 / 核心冲突 / 设定圣经 / 剧情进度 / 辅助设定
  - 每张卡可设发送优先级：**每章必发** / 常规（按相关性智能注入）/ 低频（省 token）
  - 伏笔钩子带状态追踪：埋设中 → AI 写到回收剧情时**自动标记已回收**
  - 「灵感分析」：把灵感告诉 AI，一键生成整套设定卡
- **AI 对接**：OpenAI 兼容协议 + Gemini 原生协议，内置预设：智谱GLM（glm-4-flash 免费）、硅基流动（免费模型）、DeepSeek、通义千问、Kimi、OpenRouter（:free 模型）、Gemini（免费额度）、Ollama 本地模型、自定义
  - 一键**自动获取全部模型列表**、一键**测试连接**
- **章节管理**：列表展示状态（待写/AI稿/已编辑）与字数、一键生成缺失分章大纲、增删章节
- **阅读/编辑器**：阅读模式与编辑模式切换、手动编辑保存、**AI续写**、**AI重写**、字数统计、自动记录保存时间
- **自动写作引擎**：设定章节范围 → 自动补大纲 → 逐章生成 → 每章自动保存 → 自动生成摘要 → 自动登记「剧情进度」卡 → 连续失败自动停止，实时进度与日志
- **导出与发布**：导出全书 TXT / Markdown（系统文件选择器，免权限）、复制到剪贴板、系统分享到任意APP、发布平台指南（起点/番茄/七猫/晋江/知乎盐选等）

## 300 章不跑题的机制

每章生成前，上下文组装器只注入（token 恒定，不随章节数膨胀）：

1. 「每章必发」级设定卡
2. 所有「埋设中」的伏笔钩子
3. 与本章大纲关键词相关的常规设定卡（最多14张）
4. 前 5 章**剧情摘要**（代替全文）
5. 上一章结尾 600 字（保证衔接）
6. 相邻章节大纲

写完后自动生成 120 字剧情摘要存库，供后续章节引用 —— **记得住，又不浪费 token**。

## 如何获得 APK

推送到 GitHub 后 Actions 会自动打包：

1. 打开仓库 → **Actions** → 最新一次运行
2. 页面底部 **Artifacts** 下载 `LeLe-NovelMaster-APK`
3. 解压得到 `app-debug.apk`，传到手机安装（允许未知来源）

也可在 Actions 页面点 **Run workflow** 手动触发构建。
